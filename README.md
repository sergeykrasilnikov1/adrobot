# Adrobot

Локальное приложение для создания и редактирования кампаний Keitaro. Сервер использует FastAPI, SQLAlchemy и Alembic. Интерфейс работает в браузере на HTML, CSS и JavaScript.

## Запуск

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

В `.env` задайте адрес трекера без `/admin` и API-ключ из раздела **Профиль → API ключи**. Ключу нужны права на чтение справочников, кампаний, потоков и отчётов, а также на запись кампаний и потоков.

- `KEITARO_URL` — адрес трекера, например `https://tracker.example.org`.
- `KEITARO_API_KEY` — ключ Keitaro Admin API.
- `KEITARO_TIMEZONE` — часовой пояс для отчёта за сегодня. По умолчанию `Europe/Moscow`.
- `DATABASE_URL` — URL базы SQLAlchemy. По умолчанию SQLite в файле `adrobot.db`.

```bash
alembic upgrade head
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Интерфейс доступен по адресу [127.0.0.1:8000](http://127.0.0.1:8000), OpenAPI — по адресу [127.0.0.1:8000/docs](http://127.0.0.1:8000/docs). Приложение рассчитано на локальный запуск с одним процессом Uvicorn. Для другой инсталляции Keitaro используйте отдельную БД.

## Создание и редактирование

1. Укажите название и двухбуквенный код страны, например `AU`. Выберите оффер, домен, группу и источник из справочников Keitaro.
2. При создании приложение сначала сохраняет отключённую кампанию, создаёт поток с фильтром по стране и HTTP-редиректом на Google, затем резервный поток с оффером на 100%. После создания обоих потоков кампания включается. Если настройка прерывается, приложение сообщает ID для проверки в Keitaro.
3. Откройте кампанию из списка или по ID. В потоках со схемой офферов можно добавить, убрать и вернуть оффер, закрепить либо открепить процент. Незакреплённые офферы делят остаток поровну. Остаток от целочисленного деления распределяется по одному процентному пункту в порядке списка.
4. Черновик сохраняется в БД и переживает перезапуск. **Опубликовать в Keitaro** применяет состав и доли потока. **Отменить** возвращает опубликованное состояние. Если состав или доли были изменены в Keitaro после начала редактирования, конфликт отображается в редакторе.
5. Клики, конверсии, выручку и прибыль приложение запрашивает через отчёт Keitaro по кампании, потоку и офферу.

## Проверка

```bash
python -m pip install pytest
python -m pytest -q
alembic check
```

Тесты запускают FastAPI с SQLite в памяти и имитацией API. Они проверяют параметры кампании, порядок создания потоков, отчёт, сохранение черновика, пересчёт и закрепление долей, публикацию, отмену, возврат оффера и конфликт с внешними изменениями.

[Документация Keitaro Admin API](https://admin-api.docs.keitaro.io/)
